# Quiz Creator

A simple Quiz Creator application built using Next.js and Firebase Realtime Database.

## Features
- Add quiz questions.
- Add four options (A, B, C, D).
- Select the correct answer.
- Save questions to Firebase.
- View all saved questions.

## Technologies Used
- Next.js
- React
- Firebase Realtime Database

## Screenshots

Screenshots of the application and Firebase Realtime Database are available in the `screenshots` folder.

## Run the Project

1. Clone the repository.
2. Install the dependencies:

```bash
npm install
```

3. Start the development server:

```bash
npm run dev
```

4. Open http://localhost:3000 in your browser.
